# Network Scanner
A beginner cybersecurity project built with Python.

## Description

This tool scans a target IP address for common TCP ports and identifies open services.

## Features

- Scan common ports
- Detect open services
- Fast TCP scanning
- Simple command-line interface

## Technologies Used

- Python 3
- Socket Programming
- Git
- GitHub

## Example

Scanning 127.0.0.1...

Port 22 OPEN (SSH)
Port 80 OPEN (HTTP)

Scan complete.
